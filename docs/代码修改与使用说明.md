## 二、clone 之后怎么跑起来（4 步，不需要手工配密钥）

```bash
git clone <你的仓库地址>
cd zhaoxi-huxing
```

### 第 1 步：初始化数据库（3306）

```bash
# 方式一：一键脚本（Windows）
scripts\01-init-db.bat

# 方式二：手工（密码按本机情况替换）
mysql -uroot -p --default-character-set=utf8mb4 -e "source backend/src/main/resources/init.sql"
mysql -uroot -p --default-character-set=utf8mb4 -e "source backend/src/main/resources/seed_data.sql"
```

执行后应有 **37 张表**、**13 个演示账号**（9 个业务 + 4 个 staff）。

### 第 2 步：启动后端（8080）—— 无需任何环境变量

```bash
cd backend
mvn -DskipTests package
java -jar target\javapratice-0.0.1-SNAPSHOT.jar
```

首次启动会自动完成两件事（日志里能看到 `[本地引导]` 开头的三行）：

| 自动生成的文件 | 来源 | 说明 |
| --- | --- | --- |
| `backend/.env.local` | 由 `backend/.env.local.example` 复制 | 内含本地演示的 `DB_PASSWORD=123456`，**密码不同请改这里** |
| `backend/.jwt-secret.local` | 随机生成 64 位十六进制串 | JWT 签名密钥，之后每次启动复用，删掉会导致已登录 Token 失效 |

> 两个文件都已被 `.gitignore` 排除，不会误提交。
> 也可以直接用 `scripts\02-start-backend.bat`（逻辑等价）。

验证：打开 `http://127.0.0.1:8080/doc.html` 能出接口文档即成功；
`http://127.0.0.1:8080/api/stats/overview` 未登录返回 **401 是正常的**（接口默认拒绝匿名访问）。

### 第 3 步：启动前端（5173）

```bash
cd frontend
npm install        # 或 pnpm install（仓库带 package-lock.json 与 pnpm-lock.yaml）
npm run dev
```

访问 `http://localhost:5173`（**用 localhost，不要用 127.0.0.1**，Vite 默认绑定 IPv6）。

生产构建验证（4173）：

```bash
npm run build
npm run preview     # http://localhost:4173
```

## 六、常见问题（按踩坑概率排序）

1. **`jwt.secret 未配置或长度不足 32 字节`**：正常已由启动引导兜底；若仍出现，说明 `backend/` 目录不可写（无法生成 `.jwt-secret.local`），手工设 `JWT_SECRET` 即可。
2. **`Access denied for user 'root'@'localhost' (using password: NO)`**：`backend/.env.local` 里的 `DB_PASSWORD` 与本机 MySQL 密码不一致，改那一行后重启。
3. **PowerShell 里 `JWT_SECRET=xxx java -jar` 报"无法将 xxx 项识别为 cmdlet"**：PowerShell 必须先 `$env:JWT_SECRET="..."` 再执行命令；bash 才用 `VAR=value cmd`。
4. **`Unable to access jarfile`**：未打包或路径不对，先 `cd backend && mvn -DskipTests package`。
5. **`Port 8080 was already in use`**：`netstat -ano | findstr 8080` 找到 PID 后结束进程，或 `--server.port=8081` 换端口（前端代理要同步改）。
6. **`mvn package` 报 `Unable to rename ... .jar to ... .jar.original`**：上一个后端进程还占着 jar，停掉再打包。
7. **前端 `npm run dev` 后 5173 打不开**：用 `http://localhost:5173`，不要用 `127.0.0.1`。
8. **接口返回 401 / 403**：401=没登录或 Token 过期（重新登录）；403=当前角色无权限（用对应端账号，权限矩阵见 `docs/RELEASE_CHECKLIST.md`）。
9. **算法 `/health` 返回 `loaded:false`**：权重未放置，按 `algorithm/README.md` 第三节放入 `.pt`/`.pth`（权重不入库）。

## 七、已知遗留（不影响上述端口跑通）

| # | 事项 | 影响 |
| --- | --- | --- |
| 1 | 数据备份为**占位实现**（`execMysqlDump` 只建空文件） | 备份列表有记录但文件为空，不能作为真实灾备；恢复按钮无实际效果 |

| 4 | 算法鉴权默认关闭（`FALL_API_KEY` 为空） | 公网部署必须设置 |
